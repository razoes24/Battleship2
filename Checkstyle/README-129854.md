## O que o Checkstyle não consegue verificar

O Checkstyle só verifica a **forma** do nome através de uma expressão regular. Não consegue saber se o nome é **significativo** (`MAX_SHIPS` e `XPTO_1` passam ambos) nem se descreve corretamente o valor. Também não deteta se o nome está no idioma combinado pela equipa, se é consistente com o resto do domínio (`MAX_SHIPS` vs `NUM_NAVIOS`), ou se um valor que devia ser constante está declarado sem `static final`.
