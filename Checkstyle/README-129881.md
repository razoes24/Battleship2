## O que o Checkstyle não consegue verificar

O Checkstyle só verifica a **forma** do nome através de uma expressão regular: não sabe se o nome é **significativo** (`tempoTotal` e `xpto1` passam ambos) nem se descreve corretamente o que o atributo guarda. Também não deteta nomes enganadores ou inconsistentes com o domínio (`tempoTotal` vs `totalTime`), nem se o idioma é o combinado pela equipa.
